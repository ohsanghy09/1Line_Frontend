# FastAPI 기본 서버 구현 기록

작성일: 2026-11-06. 기본 서버 실행 환경 구현 완료. 실제 OpenAI 분석·DB 연동은 미구현이다.

## 변경 내용과 코드

- `app/main.py`: FastAPI 앱과 GET `/api/health`, 응답 모델, 지정 프론트 주소의 GET CORS 설정. 향후 분석 POST를 추가할 때 허용 메서드와 통합 검증도 함께 확장한다.
- `app/config.py`: Pydantic Settings로 OS 환경변수와 AI 서버 폴더의 `.env`를 읽는다. 빈 키·모델은 미설정으로 처리하고 키는 SecretStr로 보관한다.
- `.env.example`: 값이 없는 OpenAI 키·모델 설정과 기본 CORS 주소. 실제 `.env`는 Git에서 제외한다.
- `.gitignore`: `.venv`·Python 캐시·실제 환경변수 파일 제외.
- `requirements.in` / `requirements.txt`: 직접 의존성과 검증한 설치 버전. OpenAI SDK는 설치만 했으며 클라이언트 생성·모델 호출은 아직 없다.
- `tests/test_server.py`: 실제 키나 외부 API를 사용하지 않는 서버 기본 동작 검사.

현재 PC에 `.venv`와 빈 `.env`를 준비했다. 가상환경·로컬 설정은 커밋 대상이 아니다. 실제 DB·원본 파일·기존 백엔드·프론트 요청 경로는 변경하지 않았다.

## 검증한 환경

| 항목 | 설치·실행 확인 버전 |
| --- | --- |
| Python | 3.15.2 |
| FastAPI | 0.162.0 |
| Uvicorn | 0.54.0 |
| OpenAI SDK | 3.46.0 |
| pydantic-settings | 2.16.2 |

설치 성공과 기본 서버 검증은 위 환경에서 확인한 범위다. 실제 모델 호출이나 다른 Python 버전에서의 호환성 검증을 의미하지 않는다.

## 수행한 검증

- `python -m unittest discover -s tests -v`: 5개 통과. 설정 누락 시 서버 응답, 키 비노출·연결 미확인 상태, 공백 설정, Swagger/OpenAPI 경로, CORS 허용/거부 확인.
- `python -m pip check`: 의존성 충돌 없음.
- 실제 Uvicorn을 `127.0.0.1:8000`에서 실행하여 `/api/health`, `/docs`, `/openapi.json` HTTP 200과 상태 응답 확인. 검증용 프로세스는 종료했다.
- `git diff --check`, 문서 상대 링크와 `.env`·가상환경 Git 제외 여부 확인.

실제 브라우저 Swagger 렌더링·프론트 연동·OpenAI 키 유효성·모델 호출·DB 동작은 검증하지 않았다. `/api/health`의 `connectionStatus`는 설정 유무와 관계없이 `not_checked`이며 실제 분석 준비 완료로 해석하지 않는다.
