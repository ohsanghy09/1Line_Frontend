# 개발환경과 구현 범위

기준일: 2026-11-06. [시작 안내](에이전트_시작_안내.md) · [연동 조건](../integration/handoff/배포와_서버_연결.md)

## 작성 환경은 재현 조건이 아니다

| 구분 | 기존 동작을 확인한 환경 | 수신자가 맞춰야 할 조건 |
| --- | --- | --- |
| 작업 PC | Windows·PowerShell | 동일 OS·셸 필요 없음. Linux/macOS/Windows에서 구현 가능 |
| 프론트 | React·TypeScript·Vite·Tailwind CSS, Vercel 정적 배포 | 프론트 소스를 제공하지 않으므로 같은 도구 설치 불필요. 정의된 HTTP 요청을 받아 응답할 것 |
| 백엔드 개발 구현 | Node.js·Express·SQLite | Node/Express/SQLite 선택 의무 없음. API·논리 관계·트랜잭션 효과 준수 |
| AI 개발 구현 | Python·FastAPI·Pydantic, OpenAI 구조화 응답 | Python/FastAPI/Pydantic 설치 의무 없음. 모델 출력·검증·완료 응답 제공 |
| 저장 구조 | 개발 PC의 공유 SQLite, 파일 원본은 BLOB | 같은 로컬 파일·동일 머신을 요구하지 않음. DB/객체 저장소 선택 가능, 원본 ID·초안 연결·삭제 범위 유지 |

기존 의존성 버전과 개인 가상환경은 문서만으로 실행할 대상이 아니므로 설치 기준으로 싣지 않는다. 각 파트가 선택한 스택의 실제 버전·마이그레이션·기동·배포 절차는 해당 파트가 제공한다.

## 기술과 무관한 공통 규칙

- HTTP(S), JSON 응답은 UTF-8. 업로드는 multipart/form-data이며 files 필드 반복을 지원한다.
- JSON의 생략/null/빈 문자열/빈 배열을 구분한다. 필수 키·nullable·최대 길이·추가 필드 허용 여부는 각 정의서대로 검사한다.
- 시각은 UTC ISO 8601 문자열(예: 2026-11-06T09:00:00.000Z), 활동 날짜는 YYYY-MM 또는 YYYY-MM-DD, Journey 월은 YYYY-MM이다. 화면 표시 시간대와 저장 시각을 섞지 않는다.
- MiB는 1024×1024 bytes다. 파일 수·개별 크기·합계 크기를 각각 검증한다.
- ID는 불투명 문자열이다. AI 공개 jobId는 프론트의 라우팅 구분 때문에 ai- 접두사가 필수다. 이름·배열 위치로 실제 ID를 추측하지 않는다.
- 공개 API의 backend와 AI Base를 구분한다. 도메인은 변경 가능하지만 뒤에 붙는 경로·JSON 키는 유지한다.
- 요청 취소·연결 끊김이 서버 처리 취소를 뜻하지 않는다. 작업 재조회·중복 방지·저장 결과 재확인으로 복구한다.

## DB와 모델의 선택 범위

[데이터베이스 정의](../../backend/handoff/데이터베이스_정의서.md)는 논리 엔터티와 관계를 설명한다. TEXT/INTEGER/BLOB 표기는 기존 저장 표현이며 특정 DDL 실행 지시가 아니다. 다른 SQL 자료형이나 객체 저장소를 사용해도 공개 API에는 같은 문자열 ID·파일·요약·시각을 반환한다. UNIQUE/FK/원자성의 효과는 보존한다.

이 연동 프로파일의 모델 공급자는 OpenAI이며 analysisProvider:openai를 반환한다. 언어·SDK·모델 버전·키·호출 설정은 서버에서 선택하되 모델이 구조화 출력·실제 파일 입력과 정의된 제약을 처리하는지 검증한다. Responses 방식과 호출 옵션은 기존 분석의 재현 참고이며 모든 모델/SDK가 같은 옵션을 지원한다고 가정하지 않는다. 다른 공급자로 바꾸는 것은 개발환경 변경만으로 처리할 범위가 아니며 공급자 표기·응답 계약을 별도 조정해야 한다.

## 전달 범위

이 문서 묶음만 제공하며 기존 개발 소스·개인 DB·가상환경·실행/검사 스크립트는 제공하지 않는다. API 예시의 ID·해시·도메인은 예시이며 자신의 서버에 자동 생성되지 않는다. 각 파트는 자신의 환경에 맞는 설치·실행 안내를 작성하고 실제 HTTPS 주소·인증/사용자 식별 규약·검증 결과를 프론트 담당자에게 전달한다.
