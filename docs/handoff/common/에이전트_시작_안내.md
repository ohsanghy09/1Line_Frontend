# 에이전트 시작 안내

기준일: 2026-11-06. [전체 안내](../README.md)

이 묶음은 문서만 전달하는 인수인계다. 개발 소스·개인 DB·로컬 실행/검사 스크립트를 제공하지 않는다. [개발환경과 구현 범위](개발환경과_구현_범위.md)부터 읽는다. 이 폴더만 복사해 모든 상대 링크와 계약을 확인할 수 있어야 한다.

1. [사용자 화면 정의](../review/화면별_기능_정의.md)로 기능 ID와 사용자 행동을 읽는다.
2. [서버 역할](서버별_역할과_요청_흐름.md), [데이터](공통_데이터_계약.md), [상태](상태와_오류_처리.md)를 읽는다.
3. [백엔드](../backend/README.md) 또는 [AI](../ai/README.md)의 API·데이터·분석 정의와 [서버 간 전달 계약](서버간_데이터_전달_계약.md)을 구현한다.
4. [배포 연결](../integration/배포와_서버_연결.md)의 전환 결정을 확인하고 [시나리오](../integration/연동_검증_시나리오.md)로 기능별 결과를 검증한다.

현재 홈 분석은 AI 서버, 확정 저장·조회·삭제는 백엔드다. AI는 활동을 제안하며 사용자 확정 시 백엔드가 새 활동을 생성한다. 과거 문서의 AI 자동 활동 생성·홈 목 분석·신규 활동 확인 모달 설명을 구현 요구로 가져오지 않는다. 개발용 독립 페이지도 제거했다.

필수 호환 대상은 공개 HTTP 경로·요청/응답·저장 시점·원문 근거·실패 보존 규칙이다. 언어·프레임워크·DB·저장소·큐·배포 방식은 각 파트에서 선택한다. 기존 개발환경과 같은 설치를 요구하지 않는다. 논리 DB 표는 관계와 무결성 기준이며 기존 DB 파일 이관 지시가 아니다.

환경변수의 실제 값·비밀키는 프론트에 싣지 않는다. 각 파트가 선택한 환경의 설치·실행·버전 안내를 자체 제공한다. 코드가 없는 수신자에게 작성자의 npm/Python 명령이나 파일 경로 실행을 요구하지 않는다. 이미 확정된 사용자 기능을 다시 설계 승인받을 필요는 없다. 내부 전송은 서버 간 계약의 기본 HTTP 경로·Bearer 인증·버전 규칙을 사용한다. 실제 공개 인증·사용자 범위와 주소는 배포 문서대로 연결한다.

사용자 화면·서비스·서버 검증기를 함께 바꿔야 할 때는 계약 변경 영향을 먼저 확인한다. 분석 완료와 저장 완료, 기록 요약과 활동 전체 요약, Project Timeline과 Journey를 구분한다. 실패를 빈 배열·목 성공으로 감추지 않는다.
