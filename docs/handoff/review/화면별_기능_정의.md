# 화면별 기능 정의

기준일: 2026-11-06. [전체 흐름](서비스_전체_흐름.md) · [요청 흐름](../common/서버별_역할과_요청_흐름.md) · [검증](../integration/연동_검증_시나리오.md)

아래 식별자는 API 흐름과 검증 시나리오에서 같은 기능을 뜻한다. 현재 화면 기준이며 개발용 독립 페이지는 포함하지 않는다.

## 홈 `/`

| ID | 보이는 정보·사용자 행동 | 처리 후 화면·실패 시 동작 |
| --- | --- | --- |
| HOME-01 | 글 입력, 보내기·Enter. 한글 조합 중 Enter는 전송하지 않음 | 일반 질문은 말풍선, 경험은 분석 카드. 텍스트 대기는 점 3개이며 별도 진행 폴링 없음. 실패는 안내와 재입력 가능 상태 |
| HOME-02 | 파일 선택·입력 영역 드롭, 첨부명·개수, 전송 전 개별 제거. 파일만 보내기도 가능 | 전송 후 실제 파일명 표시. 단일 파일은 변화 여부에 따라 카드 구성. 다중 파일은 유형별 개수·전체 저장·자료 확인. 파일·링크는 단계별 진행 표시 |
| HOME-03 | 링크 버튼 → HTTP(S) URL 입력·전송 | 공개 페이지 분석 후 원본 링크·유형·요약. 기존 입력 글·첨부는 유지. 비공개·내부망·지원하지 않는 링크는 실패 안내 |
| HOME-04 | 활동명·활동/자료 유형·요약이 있는 새 활동 제안 | ‘새 활동으로 저장’은 바로 활동·기록 저장. ‘기존 활동에 연결’은 카드 안 목록 선택 후 ‘선택한 활동에 저장’. 미확정은 기존 연결만 제공. 선택 취소는 저장하지 않음 |
| HOME-05 | 기존 활동 카드의 기록·아카이브 저장, 다중 파일의 전체 저장 | 성공 시 저장 완료·중복 저장 비활성화. 활동이 없어지면 기존 활동 선택 안내. 다중 파일의 ‘자료 확인’은 나의 발자국 목록으로 이동하며 자체 저장 동작은 없음 |
| HOME-06 | 카드 ‘수정’ 또는 ‘다른 활동 선택’ → 기존 활동·자료 유형 모달 | 저장 전 변경은 카드에만 반영하고 저장 버튼을 별도로 누름. 저장 후 변경은 서버에 바로 반영. 활동명·역할·기간·전체 요약 편집 항목 없음. 다중 파일 기본 카드에는 수정 버튼 없음 |
| HOME-07 | ‘북클럽 역할을 팀장으로 바꿔줘’ 같은 명시적 요청 | 역할·상태·기간·전체 요약 중 요청한 값만 변경하고 완료 말풍선. 대상이 모호하면 질문. 활동명·유형·삭제 명령은 지원 범위 밖. 새 자료는 만들지 않음 |
| HOME-08 | 홈 재진입·새로고침, ‘대화 초기화’ | 같은 탭의 대화·카드 저장 상태 복원. 작업 ID가 있으면 진행 재조회. 초기화는 새 대화로 전환하며 저장 기록·서버 작업을 삭제하지 않음. 미전송 글·File 객체는 복원하지 않음 |
| HOME-09 | 최근 활동·최근 추가 자료, 준비 상태 배지 | 최근 활동 최대 3개는 변경순, 자료 최대 3개는 최초 저장순. 활동은 상세, 자료는 해당 자료 패널로 이동. 채팅은 최근 자료에서 제외. 배지는 설정·DB 준비 상태이며 모델 성공 보장은 아님 |

실제 파일 제한은 최대 10개·각 10MiB·합계 25MiB다. 텍스트는 최대 20000자이며 텍스트 파일 본문은 UTF-8·100000자 이하다. 지원 확장자 전체는 [AI 분석 규칙](../ai/분석_입출력과_검증_규칙.md)에 있다. 지원 형식과 실제 품질 검증 완료는 구분한다.

## 나의 발자국 `/archive`

| ID | 보이는 정보·사용자 행동 | 처리 후 화면·실패 시 동작 |
| --- | --- | --- |
| ARCHIVE-01 | 활동명·유형·상태·요약·역할·기간·자료 수·최근 업데이트. 검색·유형·상태·정렬 | 검색은 활동명·요약·확정 텍스트·기록 요약·자료명 대상. 파일 원본 내부 본문은 검색하지 않음. 조건은 함께 적용. 오래된 순은 최근 업데이트가 오래된 순 |
| ARCHIVE-02 | 활동 선택 → 상세. 자료 유형별 폴더 펼치기·자료 선택 | 활동 전체 요약과 실제 파일·링크만 표시. 텍스트 경험만 저장했다면 자료 0개일 수 있음. 잘못된 활동 ID는 없음 화면, 통신 실패는 오류 화면 |
| ARCHIVE-03 | 자료 패널의 이름·유형·업로드일·AI 기록 요약·관련 변화 | 닫기·Escape·바깥 클릭으로 닫음. URL `?file=자료ID`로 직접 열기 가능. 관련 Timeline 링크는 해당 이벤트로 이동. 입력한 채팅 본문·다운로드·원본 미리보기 UI 없음 |
| ARCHIVE-04 | 활동 상세의 ‘활동 삭제’, 활동명 입력·확인 | 일치할 때만 전체 활동 삭제 후 목록 이동. 실패 시 확인창에 오류 표시하며 유지. 자료 수와 관계없이 기록·원본·타임라인까지 삭제 |
| ARCHIVE-05 | 자료 패널 삭제 아이콘 → 확인창의 삭제·취소 | 일부 파일 삭제는 남은 원본 재분석 후 완료. 실패 시 보존. 마지막 파일·링크 삭제는 해당 기록도 제거. 활동 자체는 남음. 삭제 중 버튼·닫기 제한 |

목록은 최초 로딩·조건 재조회·전체 활동 없음·검색 결과 없음·오류를 구분한다. 조건 재조회 중에는 이전 결과 조작을 막는다. 폴더 수·자료 수는 채팅 기록 수와 다르다.

## Growth Journey `/journey`

| ID | 보이는 정보·사용자 행동 | 처리 후 화면·실패 시 동작 |
| --- | --- | --- |
| JOURNEY-01 | 진입 시 저장된 전체 흐름·배지·이벤트, 마지막 분석 시각·기록 수 | 조회만 하며 모델 호출 없음. 미분석이면 안내. 기록 0개면 실행 버튼 비활성화. 조회 실패는 ‘다시 불러오기’ |
| JOURNEY-02 | ‘성장 분석하기’ 또는 ‘분석 갱신’ | 실행 중 버튼 잠금. 성공하면 결과·필터·펼침 상태 갱신. 실패하면 마지막 저장 결과임을 명시하고 재조회. 자동 모델 재호출 없음. 기록 변경 시 갱신 필요 표시 |
| JOURNEY-03 | 유형 버튼·성장 축 선택, 이벤트 클릭 | 두 필터는 이벤트 목록에 함께 적용. 전체 요약·배지는 유지. 이벤트는 저장 월 순. 펼치면 근거 인용과 가능한 전후 비교. 근거 자료 패널로 이동하는 기능은 없음 |

분석은 기록 100개·문맥 250000자, 이벤트 최대 20개·배지 10개, 유형·분야 각각 최대 8개다. 근거가 부족하면 분석 성공이어도 이벤트·배지가 없을 수 있다. 첫 경험은 제공된 기록 범위의 첫 경험이다.

## 활동 정보 상태·설정

| ID | 보이는 정보·사용자 행동 | 처리 후 화면·실패 시 동작 |
| --- | --- | --- |
| META-01 | 저장 카드·활동 상세의 ‘활동 정보를 정리하고 있어요’, 결과·실패 안내 | 저장 성공과 자동 종합 성공은 별개. 진행 중 상태만 반복 조회. 실패·최신 자료 미반영이면 ‘활동 정보 다시 분석’. 상태 조회 실패는 ‘상태 다시 확인’ |
| SETTINGS-01 | 설정 → 전체 데이터 삭제 → ‘전체 삭제’ 정확히 입력 | 분석 중이면 거절. 성공 시 현재 탭 대화 제거·완료 안내·홈으로 이동. 현재 서비스 저장 범위의 활동·파일·초안·대화·성장 결과 삭제. 기존 공개 계약에는 사용자 인증·범위 규약이 없으며 배포 연결 때 정의해야 함 |
