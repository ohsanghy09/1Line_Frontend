# 후속 화면 검토사항

정리: 2026-11-04. 기존 구현 가이드의 원본 대조 메모와 후속 설계 제안 중 아직 유용한 부분만 보존했다. 현재 구현·확정 API·새 작업 지시가 아니다. 실제 작업 시 원본 HTML·기능명세서·최신 사용자 요청을 다시 확인한다.

[현재 채팅 현황](chat/현재_구현_상태.md)과 [공통 개발 규칙](개발_규칙.md)을 먼저 참고한다. 원본은 [참고 HTML](references/1Line_reference.html), 요구사항은 [기능명세서](<references/기능명세서/개인 페이지 & 공유된 페이지/기능명세서 40363f66ceec80bdb207f2cb4e6ac0fe.md>)에 있다.

## 최근 활동·기록과 데이터 연결

- 실제 연동 시 최근 활동은 업데이트 시각으로 계산하고 기록별 활동 ID를 사용한다. 현재 홈의 /archive 이동을 상세 화면 완료로 해석하지 않는다.
- 원본의 활동 6개와 개발용 서버 활동 목록은 같은 완성 데이터가 아니다. 목록·프로필 개수·자료 총계를 실제 데이터와 일치시키는 작업이 필요하다.

## Growth Journey

- 여러 활동의 성장 이벤트이며 특정 활동의 Project Timeline과 구분한다.
- 유형·성장 분야 필터는 AND, 펼침 상태는 이벤트 ID로 관리한다. 비교 정보가 없는 카드에는 상세 펼침을 만들지 않는다. 같은 날짜 정렬은 안정적으로 유지하고 빈 결과를 안내한다.
- 원본 상단 성장 요약과 경험 배지는 고정 예시다. 필터 변경 시 요약을 재생성할지는 별도 요구로 정한다.
- 원본 성장 유형과 기능명세서의 분류 항목에 차이가 있으므로 실제 데이터 계약을 확인한다. 기존 가이드의 타입 enum을 확정 사양으로 가져오지 않는다.

## 나의 발자국

- 검색 대상 안내가 파일명·내용까지 포함하면 실제 검색도 활동명/요약만 검사하는 원본보다 확장해야 한다. 입력 정규화와 유형·상태 AND 필터를 적용한다.
- 정렬 select는 원본에서 완성된 기능이 아니다. 최근 업데이트·자료 많은 순·오래된 순을 실제 계산한다. 오래된 순이 업데이트일인지 활동 시작일인지는 구현 시 확인한다.
- 원본에 없는 활동 유형 필터를 자동 추가하지 않는다. 필터가 없는 유형도 전체 목록에서는 조회할 수 있어야 한다.

## 활동 상세·파일 Drawer·Project Timeline

- 활동 상세와 Timeline 이동은 같은 활동 ID를 유지한다. 상세 경로 제안은 /archive/:activityId와 /archive/:activityId/timeline이었으나 아직 확정 경로가 아니다.
- 폴더는 독립적으로 접고 펼친다. 활동 변경 시 이전 자료 선택을 정리하고 폴더 없음·빈 폴더·잘못된 활동/자료 ID를 구분한다.
- 원본 파일 Drawer는 제목만 선택한 파일로 바꾸고 본문은 와이어프레임 예시를 재사용한다. 실제 구현에서는 파일 ID로 해당 요약·버전·변화·관련 이벤트를 조회한다. 변화 없는 자료에는 비교·Turning Point를 만들지 않는다.
- Drawer는 원본에서 모바일 전체 폭, sm 이상 440px의 우측 패널과 0.25초 등장 모션이다. 닫기 애니메이션·다운로드·미리보기를 자동 추가하지 않는다.
- Timeline의 이벤트/Turning Point 개수는 데이터로 계산한다. 원본의 고정 숫자·이벤트를 다른 활동에 재사용하지 않는다. Before/After·Reason·Evidence는 해당 이벤트의 값이어야 한다.
- 저장·수정 후 관련 자료·폴더·목록·개수를 동기화한다. Timeline과 Journey를 동시에 무조건 추가하지 않는다.

## 원본 예시 데이터 검토

다음은 기존 가이드가 원본에서 발견한 불일치다. 실제 연동이나 목데이터 확대 시 원본을 재확인하고 보정하며 실제 사용자 이력으로 간주하지 않는다.

- 1호선톤 표시 자료 총계 14개와 예시 파일 배열 11개가 다르다. 개발·발표 폴더도 표시 개수와 배열이 다르다.
- 컴퓨터비전의 활동/폴더 표시 개수와 예시 파일 배열도 다르다. 전체 목 목록이면 실제 배열로 통일하거나 근거 있는 fixture를 채우고, 부분 조회면 totalCount와 로드 개수를 구분한다.
- Journey의 2026.03 1호선톤 이벤트와 활동 시작 2026.10이 맞지 않는다. 미래 날짜를 포함한 파일 fixture도 기준 연도를 명시해 검토한다.
- 원본의 중복 글자·빈 결과 오타 등은 구현 화면에서 바로잡을 수 있지만 참고 HTML을 먼저 수정하지 않는다.

기존 가이드의 홈 → Journey → 나의 발자국 → 상세/Timeline 순서는 당시 화면 개발 제안이었다. 다음 실제 작업과 우선순위는 최신 사용자 요청으로 정한다. Growth Map은 기능명세서상 후순위 선택 기능이며 이번 채팅 작업의 완료 범위에 포함하지 않는다.
