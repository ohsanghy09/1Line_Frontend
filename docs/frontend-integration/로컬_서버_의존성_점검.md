## 점검 원칙

### 2026-11-11 개발 서버 제거 완료

기준 커밋 f54e497 이후 사용자 요청으로 api-server·ai-api-server와 check-live-ai를 제거했다. 제거 전 서버 소스·검사·DB·AI .env·수동 검사 84개 파일을 프로젝트 밖 임시 백업에 복사·대조했다. 백업 경로와 SHA-256 manifest 위치는 [검증 기록](변경_협의_및_검증_기록.md)에 남겼다. 아래 서버 경로·DB 의존성 표는 제거 전 조사 이력이다. 현재 프론트의 실행 소스·tests·scripts에는 서버 소스 참조가 없다. 제거 후 npm test 39개·세션 복원·빌드·Swagger 생성 통과, lint는 기존 경고 3개·오류 0개다. 외부 백업과 기준 커밋으로 서버 자료를 보존하며 원격 연동은 별도 후속 범위다.

## 실행과 문서 생성의 연결

`npm run dev`는 predev → docs:build → build-swagger를 거친다. `npm run build`도 prebuild에서 같은 경로를 거친다.

최초 조사 당시 파일 참조는 다음 순서로 이어졌다.

1. `scripts/build-swagger.mjs`가 `api-server/docs/openapi.js`의 backendSpec·aiSpec을 import한다.
2. openapi는 서버 validation·journey 스키마와 chat-examples.json·ai-openapi.json을 읽는다.
3. journey는 database와 journey-context를 import하고 database는 node:sqlite를 import한다. 문서 생성 자체는 DB를 열지 않는다.
4. 생성물은 `public/swagger/`, 빌드 결과는 `dist/`에 기록된다. 두 경로 모두 Git에서 제외된다.

현재는 handoff 기준의 `docs/frontend-integration/openapi/backend.openapi.json`·`ai.openapi.json`을 작성하고 build-swagger가 읽도록 전환했다. 공개 20개·내부 6개의 호출 주체와 서버 전용 Bearer 인증을 표시했다. 기존 서버 소스의 import 경로를 사용하지 않는다.

## 연결 설정과 배포

- VITE_API_BASE_URL·VITE_AI_API_BASE_URL은 각각 /api를 포함한 Base다. 서비스에서 끝 슬래시 하나를 제거하며 ID 경로는 인코딩한다.
- 두 변수는 Vite 빌드 시 클라이언트 코드에 반영된다. 배포 뒤 환경변수를 바꾸면 새 빌드가 필요하다.
- 로컬 Vite preview는 별도 proxy 설정이 없으면 server.proxy를 상속한다. 설치된 Vite의 resolvePreviewOptions 구현에서 확인했다. Vercel 정적 배포에는 이 Vite 프록시가 적용되지 않는다.
- 따라서 프론트 정적 화면을 띄우는 것과 원격 API로 기능이 동작하는 것은 각각 확인해야 한다. 실제 서버 URL·CORS·인증은 서버 준비 후 연결 검증 대상이다.
- 이번 환경에는 루트 .env 파일이 없고 실제 원격 주소도 설정 파일에서 확인되지 않았다. 환경변수의 비밀값은 읽거나 문서에 기록하지 않았다.

## 서버 영역과 파일 보존 확인

- 서버 두 폴더에는 Git 추적 파일이 합계 74개 있다. 이번 검색에서 추적되지 않은 일반 파일은 확인되지 않았다.
- 백엔드 data·.env·node_modules와 AI .env·.venv·Python 캐시는 서버별 .gitignore 대상이다. 이번 환경에서는 백엔드 data·AI .venv·실제 .env가 확인되지 않았다. 다른 PC나 외부 DB_PATH·AI_DB_PATH에 있는 데이터 존재 여부는 여기서 확정할 수 없다.
- 백엔드의 활동 종합·Journey 요청은 ID 경로 또는 본문 없는 요청으로 AI가 공유 DB를 조회하게 한다. 남은 파일 분석은 {fileId}만 보낸다. handoff의 분리 서버 구현은 문맥·초안·원본 전달을 별도로 정의한다. 이는 서버 담당 범위다.
- 프론트 sessionStorage에는 대화·카드·작업 ID를 저장한다. 원본 File과 서버 DB의 영속 기록은 이 저장소에 포함되지 않는다.
- 서버 폴더 제거 여부는 이 조사와 독립 전환의 검증 결과를 확인한 뒤 결정한다.
