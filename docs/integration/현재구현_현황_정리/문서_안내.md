# 화면별 현재 구현 현황

정리일: 2026-11-05

## 목적과 읽기 순서

백엔드·AI 담당자에게 전달할 현재 구현 현황이다. 기존 인수인계 문서와 페이지·서비스·서버 라우트를 대조했다. 최종 API 계약이나 전체 기능명세의 완료 보고서는 아니다.

| 순서 | 문서 | 화면 경로 |
| --- | --- | --- |
| 1 | [공통 화면](공통_화면.md) | MainPage·Sidebar |
| 2 | [홈 채팅](홈_채팅.md) | `/` |
| 3 | [나의 발자국 목록](나의_발자국/나의_발자국_목록.md) | `/archive` |
| 4 | [활동 상세](나의_발자국/활동_상세.md) | `/archive/:activityId` |
| 5 | [자료 상세 패널](나의_발자국/자료_상세_패널.md) | `/archive/:activityId?file=:fileId` |
| 6 | [프로젝트 타임라인](나의_발자국/프로젝트_타임라인.md) | `/archive/:activityId/timeline` |
| 7 | [성장 여정](성장_여정.md) | `/journey` |

자료 상세 패널은 활동 상세 안에서 여는 Drawer이며 독립 페이지가 아니다. 개발용 채팅 카드 미리보기는 이번 문서 범위에서 제외한다. Growth Map·로그인·설정은 현재 [라우트](../../../src/App.tsx)에 구현된 화면이 아니다.

## 전체 연결 상태

현재 연결은 프론트 → 로컬 개발 서버 → SQLite 또는 서버 목 분석이다. 실제 협업 백엔드나 외부 AI API 연결은 아직 없다.

| 영역 | 실제 처리 | 목 분석·미연결 |
| --- | --- | --- |
| 홈 | 입력 접수·파일 보관·초안·작업·확정 기록 저장·수정, 최근 목록 조회 | 분류·요약·변화 판단·진행 단계는 목 응답 |
| 아카이브·Timeline | 확정 기록과 자료·이벤트의 DB 조회·집계·검색 | 저장된 분석 내용은 목 값일 수 있음. 실제 파일 본문 분석·버전 관계 없음 |
| Journey | HTTP 조회·검증·필터·상세·재시도 | 서버 목 응답. DB 분석·실제 AI·결과 저장 없음 |
| 공통 | 활동 개수 조회·경로별 메뉴 표시 | 프로필은 고정 예시. 인증·설정 기능 없음 |

DB에 저장됐다는 사실과 실제 AI 분석이라는 사실을 구분한다. 분석 초안을 만든 것과 사용자가 확정 저장한 것도 다르다.

## 공통 API·검증 기준

- 문서의 API는 현재 로컬 서버 계약이다. 최종 백엔드 경로·응답으로 확정하지 않는다.
- [request 헬퍼](../../../src/services/chat.ts)는 `VITE_API_BASE_URL` 또는 `/api`를 사용한다. 개발 시 [Vite 프록시](../../../vite.config.ts)는 `127.0.0.1:3001`로 연결한다.
- 현재 요청 제한은 개별 HTTP 30초다. 인증·사용자별 권한은 개발 서버에 구현하지 않았다.
- 이번 정리에서는 문서·소스 대조와 문서 링크 검사를 수행한다. API 실행·빌드·테스트·실제 브라우저 검사를 새로 수행한 결과는 아니다.
- 화면별 검증 항목은 기존 문서의 보고다. 기존 자동 검사 통과와 사용자 확인, 미검증 항목을 구분한다.

## 후속 작업

이 문서들을 바탕으로 [작업 계획](../작업_계획.md)의 프론트–백엔드 및 백엔드–AI 계약을 작성한다. 각 화면의 후속 항목은 협의·구현 대상이며 현재 구현됐다는 의미가 아니다.
