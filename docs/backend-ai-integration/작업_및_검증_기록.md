# 작업 및 검증 기록

문서·코드 조사, 기능 구현, 로컬 검사, 실제 서버 연동 검증을 구분한다. 실행하지 않은 검사는 통과로 기록하지 않는다. 비밀 토큰이나 사용자 원문을 기록하지 않는다.

## 2026-11-13 — 작업 범위 정리 및 문서 작성

### 확인한 방향

- 공유 DB에 의존하는 백엔드·AI 연동을 내부 HTTP 데이터 전달로 변경한다.
- 활동 정보 분석, 파일 일부 삭제 후 재분석, 홈 분석 데이터 전달, 서버 간 인증을 구현 대상으로 정리했다.
- 기존 프론트 공개 API를 유지한다. 실제 연동에서 차이가 드러나면 영향과 필요한 수정을 기록한다.
- 서버 간 토큰은 양쪽 서버에만 설정하고, 송신·수신 코드와 HTTPS를 함께 적용한다.
- 이번 요청은 계획·기록 문서 작성이다. 기능 구현이나 배포를 완료한 것으로 해석하지 않는다.
