# Growth Journey 수정

작성일: 2026-11-12

## 목적

성장 유형을 AI 자유 생성 방식에서 고정 5종으로 변경하고, 성장 카드에 유형별 판단 이유와 실제 근거 기록을 표시한다. 하나의 이벤트에 여러 유형을 허용하되, 근거가 부족하면 유형이나 이벤트를 만들지 않는다.

이 폴더는 확정 정책·공통 계약·AI 전달 요구사항·검증 기록을 관리한다. Spring·DB와 React 프론트에 새 계약을 적용했다. 사용자의 최신 지시로 OpenAPI·Swagger도 같은 계약에 맞춰 갱신했다. 이전의 명세 수정 제외 지시는 해제됐다. 실제 AI 구현·연동·배포와 브라우저 조작·시각 검증은 미검증이다.

## 작업 범위

- 이 저장소의 React 프론트와 `api-server-spring/` 소스를 수정한다.
- 공통 계약, DB 변경, AI 전달 문서와 로컬 검사를 정비한다. 최신 추가 요청에 따라 OpenAPI·Swagger도 갱신한다.
- AI 서버 소스는 이 저장소에 없으므로 AI 담당자가 구현할 요구사항과 예시를 작성한다.
- Spring은 이후 JAR로 빌드해 AWS EC2에서 실행하는 구조다. 실제 연동과 배포는 이번 범위에 포함하지 않는다.
- 홈 채팅·기록 저장·활동 아카이브·Project Timeline의 기존 기능은 유지한다.
- 사용자 확인상 DB가 비어 있으므로 이전 분석 결과 호환·변환·이전 기준 안내는 제외한다. DB 내용 확인이나 삭제를 수행한 것은 아니다.

## 화면

- 필터: 전체 / 능력 확장 / 성과 향상 / 경험 축적 / 효율성 / 경험 전이
- 선택한 유형이 포함된 카드를 표시한다. 필터 여러 개를 동시에 선택하는 기능은 아니다.
- 카드 클릭 시 유형별 짧은 판단 이유, 간결한 Before/After와 비교 조건, 경험 전이 연결 설명을 표시한다.
- '근거 기록 보기'를 추가로 펼치면 중복을 정리한 원문 인용·출처와 관련 판단 유형·역할을 표시한다. 검증용 상세 데이터는 JSON에 유지한다.
- 기존 성장 분야 필터를 유지하고 유형 필터와 함께 적용한다.

## 확정 정책 요약

- 한 문장·한 기록의 Before/After와 경험 전이도 근거가 명확하면 허용한다.
- 모든 유형에 reason/evidence 필수. 성과 향상·효율성에는 comparison, 경험 전이에는 transfer 필수다.
- 출발 활동의 별도 DB 등록은 요구하지 않는다. 실제 적용 활동은 기존 기록의 활동 ID를 사용한다.
- 근거 부족은 정상 빈 결과, 형식·실제 근거 오류는 저장 거절이다.
- 재분석 실패 시 마지막 유효 결과를 유지하되 삭제로 무효화된 결과는 복원하지 않는다.
- 버전·제한의 상세 값은 공통 계약을 따른다. 실제 연동 성공을 의미하지 않는다.

## 현재 검증 결과

Spring 회귀 검사 11개와 새 Journey 검사 8개, 총 19개 통과. 새 Journey 검사에는 잘못된 공급자 응답 29종과 코드 포인트 길이 경계 확인이 포함된다. 실행 JAR는 `api-server-spring/build/libs/1line-api-server-0.1.0.jar`에 생성했다. JDK 21과 Gradle 9.5.1을 사용했고, Windows 한글 경로 문제는 전용 ASCII 캐시·임시 경로로 우회했다. 실행 명령과 검증 범위는 [기록](작업_및_검증_기록.md)에 있다.

프론트는 Swagger 생성 검사를 제외한 테스트 44개, 별도 채팅 세션 검사, lint, TypeScript·Vite 빌드를 통과했다. 카드 JSX를 실제 React 서버 렌더러로 검사했으며 DOM 조작·화면 캡처 검증은 아니다. 브라우저 연결 호스트 부재로 실제 클릭·키보드·좁은 화면 확인은 수행하지 못했다. Spring 테스트 결과는 이전 단계의 이력이며 이번 프론트 작업에서 재실행하지 않았다.

OpenAPI·Swagger 추가 갱신 후에는 전체 테스트 51개·세션 검사·lint·Swagger 자동 생성을 포함한 빌드가 통과했다. 정식 JSON Schema 검증기로 스키마·예시·거절 사례 56개를 확인했다. Swagger에는 원문 25개와 전체 교환 예시 JSON을 포함한다. 실제 서버 연동·배포·브라우저 렌더링은 이 결과에 포함되지 않는다.
