## 2026-11-12 — 확정 정책과 공통 계약 갱신

### 확정한 정책

- 사용자 확인상 DB는 비어 있다. 기존 분석 결과 호환·변환·이전 기준 안내를 제외한다. DB를 조회하거나 삭제하지 않았다.
- 한 기록·한 문장에서도 비교와 경험 전이를 인정한다. 양쪽 역할에 같은 인용문을 사용할 수 있다.
- 모든 판단에 reason/evidence, 성과 향상·효율성에 comparison, 경험 전이에 transfer를 필수로 한다.
- 출발 활동은 미등록이어도 명시적 근거가 있으면 인정하되, 적용 활동은 실제 기록에 연결한다.
- 상세는 짧은 판단·비교·전이 설명을 먼저 표시하고 원문 출처는 추가로 펼친다.
- 근거 부족은 정상 빈 결과, 잘못된 응답은 저장 거절. 재분석 실패 시 마지막 유효 결과를 유지하고 삭제 무효화는 우선한다.

### 문서에 정한 구현 세부값

- schemaVersion=journey-result-v2, criteriaVersion=growth-criteria-v1, promptVersion=journey-v6.
- 비교 조건과 양쪽 근거, 경험 전이의 출발·적용 근거를 명시했다. 제한·오류·빈 결과·DB 초기화 규칙도 기록했다.
- evidenceSources를 공개 결과에 추가해 Spring이 실제 기록 ID와 활동명으로 원문 출처를 제공하도록 했다. 공급자 result에는 포함하지 않는다.
- examples/journey-exchange.json에 한 기록의 복수 유형 요청·공급자 응답·공개 응답을 작성했다. fingerprint는 실제 해시가 아닌 형식 예시다.
- 기존 handoff의 실행 계약을 당장 새 구현으로 오인하지 않도록 새 계약 안내를 추가했다. OpenAPI 스키마와 기능 코드 갱신은 구현 단계에서 수행한다.

### 검증 범위

## 2026-11-12 — OpenAPI·Swagger 추가 요청 반영

### 범위 변경과 구현

- 사용자가 OpenAPI·Swagger 갱신을 새로 요청했다. 이전의 수정 제외 지시를 해제하고 문서·완료 범위를 최신화했다.
- backend.openapi.json: 고정 5종, 유형별 판단 배열·필수 비교/전이·출처·버전·제한, 미분석/유보/삭제/정상 응답 예시와 오류 설명을 반영했다.
- ai.openapi.json: 버전이 있는 전체 입력·공급자 응답, journey-v6, 한 문장 비교·미등록 출발 활동, Spring 전용 필드 금지를 반영했다.
- 공통 Evidence 등 다른 API가 공유하는 스키마는 그대로 두고 Journey 전용 근거·판단 스키마를 추가했다. 동적 근거 부분집합·활동·날짜·중복 유형은 서버 검증이라는 한계를 명시했다.
- build-swagger.mjs: 최신 작업 문서 4개를 원문 묶음에 추가하고 전체 교환 JSON을 복사·연결한다. 기존 21개와 합쳐 Markdown 페이지 25개를 제공하며 읽기 전용 설정을 유지한다.
- 기존 handoff의 Journey 이전 규칙은 최신 계약이 우선함을 안내했다. AI API 안내의 구형 응답 예시는 새 전체 응답으로 교체했다.

### 검증

- npm test: 전체 51개 통과, 별도 채팅 세션 복원 검사 통과.
- npm run lint: 오류·경고 0. npm run build: Swagger 정적 생성·TypeScript·Vite 빌드 통과.
- scripts/check-journey-openapi.py: 정식 Draft 2020-12 JSON Schema 검증 56개 통과. 스키마·정상 예시 및 필수 비교/전이 누락·구형 필드·버전·출처·길이 오류 거절을 검사했다.
- 정식 검증기는 프로젝트 패키지에 추가하지 않고 임시 폴더에 jsonschema 4.26.0을 설치해 사용했다. 네트워크 및 임시 설치 폴더 접근 제한은 승인된 실행으로 해결했다.
- Swagger 생성물은 public/swagger 및 dist/swagger에 있으며 Git에서 제외한다. 실제 배포·AI 실행·원격 통신·브라우저 렌더링은 수행하지 않았다.
- 로컬 preview에서 Swagger HTML·두 명세 JSON·CSS·작업 안내·공통 계약·AI 전달 문서·전체 교환 JSON의 HTTP 200을 확인했다. 검사 후 임시 preview 서버를 종료했다.
- Git 기준과 비교해 Journey 외 API 경로·공용 스키마가 그대로임을 확인했고, public/swagger와 dist/swagger 명세 JSON이 원본과 일치함을 확인했다.
