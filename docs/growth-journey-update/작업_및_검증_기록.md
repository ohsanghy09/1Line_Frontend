## 2026-11-12 — 확정 정책과 공통 계약 갱신

### 확정한 정책

- 사용자 확인상 DB는 비어 있다. 기존 분석 결과 호환·변환·이전 기준 안내를 제외한다. DB를 조회하거나 삭제하지 않았다.
- 한 기록·한 문장에서도 비교와 경험 전이를 인정한다. 양쪽 역할에 같은 인용문을 사용할 수 있다.
- 모든 판단에 reason/evidence, 성과 향상·효율성에 comparison, 경험 전이에 transfer를 필수로 한다.
- 출발 활동은 미등록이어도 명시적 근거가 있으면 인정하되, 적용 활동은 실제 기록에 연결한다.
- 상세는 짧은 판단·비교·전이 설명을 먼저 표시하고 원문 출처는 추가로 펼친다.
- 근거 부족은 정상 빈 결과, 잘못된 응답은 저장 거절. 재분석 실패 시 마지막 유효 결과를 유지하고 삭제 무효화는 우선한다.

### 문서에 정한 구현 세부값

- schemaVersion=journey-result-v2, criteriaVersion=growth-criteria-v1, promptVersion=journey-v6.
- 비교 조건과 양쪽 근거, 경험 전이의 출발·적용 근거를 명시했다. 제한·오류·빈 결과·DB 초기화 규칙도 기록했다.
- evidenceSources를 공개 결과에 추가해 Spring이 실제 기록 ID와 활동명으로 원문 출처를 제공하도록 했다. 공급자 result에는 포함하지 않는다.
- examples/journey-exchange.json에 한 기록의 복수 유형 요청·공급자 응답·공개 응답을 작성했다. fingerprint는 실제 해시가 아닌 형식 예시다.
- 기존 handoff의 실행 계약을 당장 새 구현으로 오인하지 않도록 새 계약 안내를 추가했다. OpenAPI 스키마와 기능 코드 갱신은 구현 단계에서 수행한다.

### 검증 범위

- 실행 결과: 새 작업 문서의 상대 링크, JSON 파싱, 예시의 버전·허용 유형·중복·근거 원문·역할별 근거 포함 관계·적용 활동 연결 검사를 통과했다.
- git diff --check 통과. Git의 LF→CRLF 변환 안내는 있으나 공백 오류는 없었다.
- 기능 코드·DB 변경 및 프론트/Spring 테스트·빌드는 이번 문서 갱신에서 수행하지 않는다.
- 실제 AI 메시지 전달·실행·연동·배포는 수행하지 않는다.

## 2026-11-12 — Spring·DB 구현 및 로컬 검증 완료

### 구현

- JourneyContract.java: 고정 유형·버전·코드 포인트 길이·중첩 근거·필수 comparison/transfer·분야 참조·금지 필드 검증을 분리했다.
- Journey.java: 기존 해시 계산을 유지하며 전체 기록 요청 본문을 구성했다. 최초 전송 해시·AI 반환 해시·현재 DB 해시를 모두 비교한 뒤 저장한다.
- 한 기록의 비교, 동일 인용문을 양쪽 역할에 사용하는 경우, 미등록 출발 활동을 허용한다. 등록 출발 활동은 실제 근거 관계를 확인하고 활동명을 DB 값으로 정규화한다.
- evidenceSources를 실제 기록에서 구성한다. 이벤트 날짜는 가장 늦은 근거 저장 시각을 UTC로 정규화한 월과 대조한다.
- Database.java: 새 DB 및 빈 기존 테이블에 criteria_version 컬럼을 구성한다. INSERT에 컬럼명을 명시했다. 기존 개인 DB를 열거나 자료를 삭제하지 않았다.
- ArchiveDelete.java: 삭제 시 새 계약의 빈 결과로 교체해 중첩 설명·비교·전이·출처를 모두 제거하고 고정 필터는 유지한다.
- ApiTest.java의 구형 Journey 전용 검사는 JourneyTest.java의 새 계약 검사로 대체하고 기존 다른 API 회귀 검사는 유지했다.

### 검증의 한계와 다음 작업

- 임시 SQLite와 테스트용 HTTP AI 서버를 사용했다. 실제 AI 모델의 의미 판단, 실제 서버 간 인증·CORS·네트워크·시간 초과 상황은 검증하지 않았다.
- 프론트·OpenAPI는 아직 구형 구조이므로 새 Journey 응답과 맞지 않는다. 다음 단계에서 수정한다. 프론트 DOM·브라우저 검증도 이번 결과에 포함되지 않는다.
- 실제 AI 담당자에게 메시지를 보내지 않았다. 구현·버전 지원 확인과 실제 연동·배포는 후속 작업이다.
