# 작업 및 검증 기록

설명·코드 조사·구현·로컬 검사·실제 연동 확인을 구분해서 기록한다. 실행하지 않은 검사를 통과로 표시하지 않는다.

## 2026-11-12 — 작업 범위 정리 및 문서 구성

### 사용자와 정리한 방향

- 고정 5종 성장 기준과 유형별 판단 이유·근거를 도입한다.
- 하나의 이벤트에 여러 유형을 허용하고, 선택한 유형을 포함한 카드를 표시한다.
- 이 저장소에서 프론트와 Spring을 수정하며 AI 담당자에게 전달할 계약·요구사항을 작성한다.
- 실제 서버 연동·실제 AI 검증·배포는 후속 작업이다.
- Spring 소스는 이 저장소에서 관리하고, 이후 JAR로 EC2에 배포한다.
