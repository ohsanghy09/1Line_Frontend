# AI 담당자 전달사항 초안

작성일: 2026-11-12 · 상태: 요구사항 초안, 실제 전달·AI 구현 미확인

## 변경 목적

Growth Journey의 자유 성장 유형 생성을 고정 5종 판단으로 변경한다. [공통 JSON 계약](공통_JSON_계약.md)을 최종 확정한 뒤 동일한 요청·응답 구조로 구현한다. AI 서버 구현과 실제 연동·배포는 이번 저장소 작업의 완료 조건이 아니다.

## 인정·제외 조건

| 유형 | 인정 조건 | 제외 조건 |
| --- | --- | --- |
| 능력 확장 | 이전에 수행하지 않았던 기술·역할·업무를 실제 수행한 기록 | 새 기술을 알아보거나 학습 계획만 작성 |
| 성과 향상 | 비교 가능한 활동의 성능·결과·성과 개선 | 이전 결과가 없거나 비교 조건이 지나치게 다름 |
| 경험 축적 | 기존 기록에서 확인되지 않았던 새 활동·경험을 실제 수행 | 동일한 기존 경험이거나 실제 수행 여부 불명확 |
| 효율성 향상 | 유사한 결과 수준을 유지하며 시간·자원 절감 | 반복 사실만 있고 결과 수준·효율 확인 불가 |
| 경험 전이 | 이전 활동의 지식·경험·피드백을 다른 활동에 실제 활용 | 두 활동에서 같은 기술을 사용했다는 사실만 확인 |

판단 범위는 제공된 기록이다. 사용자의 전체 삶에서 처음이라고 단정하지 않는다.

## 출력 요구사항

- 허용된 5개 유형 ID만 사용한다. 고정 라벨·아이콘·필터를 자유 생성하지 않는다.
- 이벤트별 growthAssessments 배열에 type, reason, evidence를 반환한다.
- 여러 유형은 허용하지만 같은 이벤트 안에서 같은 유형은 중복하지 않는다. 유형별로 인정 조건을 충족해야 한다.
- 비교 가능한 경우 해당 판단에 comparison의 before/after를 제공한다. 원문에 없는 수치·조건·인과관계를 추정하지 않는다.
- 근거가 없으면 판단과 이벤트를 만들지 않는다. 다섯 유형의 개수를 채우지 않는다.
- 기존 evidenceCatalog의 evidenceId 선택 방식을 유지한다. 모델은 인용문을 재작성하지 않고, AI 서버가 실제 recordId와 quote로 복원해 Spring에 반환한다.
- summary·badges·분야(axis)의 기존 근거 및 참조 규칙을 보존한다.
- 전달받은 sourceFingerprint와 기준 버전을 응답에 연결한다. 결과 확정 저장은 Spring이 담당한다.

## 담당자용 판단 예시

| 입력 사례 | 기대 판단 |
| --- | --- |
| “새 기술을 공부할 계획이다.” | 실제 수행 근거가 없으므로 능력 확장 제외 |
| “기록상 처음 서버 배포를 직접 완료했다.” | 실제 새 업무 수행이 뒷받침되면 능력 확장 인정 가능 |
| 동일 조건의 테스트에서 성공률 70% → 95% | 성과 향상 인정 가능 |
| 서로 다른 난이도의 테스트에서 점수 상승 | 비교 가능성이 부족하면 성과 향상 유보 |
| 기존 기록에 없는 사용자 인터뷰를 직접 수행 | 경험 축적 인정 가능 |
| “같은 작업을 또 했다.” | 반복만으로 경험 축적을 부여하지 않음 |
| 같은 테스트를 통과하며 배포 시간 30분 → 5분 | 효율성 향상 인정 가능 |
| “더 빨라졌지만 결과가 같은지는 모르겠다.” | 결과 수준 근거가 부족하면 효율성 향상 유보 |
| A 활동에서 익힌 방법을 B 활동에 적용했다는 명시적 기록 | 양쪽 활동 근거가 있으면 경험 전이 인정 가능 |
| A·B 활동에서 모두 React를 사용 | 같은 기술 사용만으로 경험 전이 인정하지 않음 |

이는 프롬프트와 평가용 예시이며 실제 모델 검증 결과가 아니다. 실제 적용 시 각 사례에 사용할 기록 원문·근거 ID·기대 JSON을 추가한다.

## 추가 협의

- 이전·이후 비교에 서로 다른 기록 2개를 요구하는 현재 정책의 유지 여부.
- 경험 전이에서 출발 활동과 적용 활동의 표현·검증 방식.
- 기존 분리 서버 요청 계약과 AI 실제 구현의 일치 여부. 현재 Spring은 본문 없이 호출하므로 요청 구성 수정이 필요하다.
- 최종 버전·전체 스키마·제한·오류 응답을 합의하고 OpenAPI와 예시를 갱신한다.
