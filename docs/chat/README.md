# 채팅 기능 문서

홈 채팅 관련 문서를 이 폴더에 모았다. 공통 [개발 규칙](../개발_규칙.md)과 원본·기능명세서·캡처가 있는 [참고 자료](../README.md)는 상위 docs에서 관리한다.

## 읽는 순서

1. [현재 구현 상태](현재_구현_상태.md): 구현·목 응답·실제 API 연결·남은 작업·검증 범위.
2. [기능별 구현 기록](구현_기능/README.md): 채팅·파일·링크·카드 저장/수정·세션.
3. [실제 서버 전환 가이드](api/실제_서버_전환_가이드.md): 백엔드·AI 연결 시 변경할 위치와 계약.
4. [개발 기록](개발_기록.md): 날짜별 변경 이력.

## 폴더와 코드

- 구현_기능/: 현재 화면 동작·관련 코드·검증·미구현 사항.
- api/: 로컬 REST API·화면용 데이터·진행 조회와 실제 서버 전환 설명.
- src/components/chat/: 채팅 카드·진행·상태·시각·공통 버튼.
- src/components/chat/modals/: 기록 분류 수정·링크 입력 모달.

페이지는 src/pages/Home.tsx다. 서비스·타입·유틸·api-server는 기존 위치를 유지한다. 다음 기능의 문서와 컴포넌트는 이 채팅 폴더와 구분한다.
