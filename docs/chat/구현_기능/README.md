## 앞으로 기능을 만드는 방식

2026-11-03 사용자 확인: 카드와 다른 UI도 현재 단일 파일 카드와 같은 방식으로 개발한다.

**실제 입력 → 서비스 → 타입이 있는 목 응답 → 응답 데이터로 화면 표시 → 추후 실제 API로 교체**

실제 파일명·개수·입력 글·시각은 보존하고, API 연결 전의 활동 분류·요약·변화 판단 등은 목데이터로 제공한다. 화면은 응답 값에 따라 같은 카드 구조를 사용하고 변화 없음 등의 분기도 처리한다. 분석 예시를 실제 분석 결과나 저장 완료로 설명하지 않는다. 시연 버튼은 제거했으며 실제 입력으로 기능을 확인한다.

기능을 추가할 때 필요한 데이터·처리·화면부터 나누고, 기능별 문서에 위치와 현재 동작을 기록한다. 전체 원칙은 [개발 규칙](../../개발_규칙.md)을 따른다.
