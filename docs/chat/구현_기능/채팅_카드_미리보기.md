# 채팅 카드 미리보기

최종 정리: 2026-11-04

## 화면

개발 서버에서 /example을 연다. 공통 사이드바 밖의 독립 페이지로 홈 복귀 링크를 제공한다.

- 텍스트 경험, 단일 파일 변화 있음/없음, 다중 파일 결과 카드
- 고정 목 진행 카드
- 준비됨·사용 불가·조회 중·조회 실패 배지

실제 홈의 카드·진행·상태 컴포넌트와 기존 프론트 목 데이터를 재사용한다. 홈의 서버 목 모드를 변경하지 않고 결과 4종을 함께 확인한다.

## 버튼·데이터

기록·저장은 실제 로컬 API를 사용한다. 수정·다른 활동 선택은 같은 분류 수정 모달을 연다. 저장 전 수정은 카드 상태, 저장 후 수정은 DB에 반영한다. 수정한 응답 JSON은 카드 아래 펼침에도 표시한다. 다중 파일에는 전체 저장·자료 확인 두 버튼을 유지하며 자료 확인은 /archive 이동이다.

예시 파일명만으로 파일 원본을 생성하지 않는다. 새 분석을 접수하는 페이지가 아니며 진행·상태 배지는 고정 미리보기다. 시간은 페이지를 연 시점으로 고정한다.

미리보기의 저장 ID는 페이지 메모리에서만 관리한다. 홈의 sessionStorage 보관과 달리 재진입 후 저장하면 별도 기록이 추가될 수 있다.

## 위치·검증

src/examples/ExamplePage.tsx, App.tsx, 공통 카드 컴포넌트와 src/mocks/Home 데이터를 사용한다.

초기 페이지의 React 서버 렌더링 검사와 후속 카드 4종 API 저장·수정·이벤트 검사가 통과했다. 실제 브라우저 클릭·반응형 검증은 미실시다. [카드 기록·수정](카드_기록_수정.md)을 참고한다.
