# 채팅 서비스 준비 상태

최종 정리: 2026-11-04

Home → getChatServiceStatus() → GET /api/health → ChatServiceStatusBadge 순서로 표시한다.

```json
{ "status": "ready", "label": "기록 정리 준비됨", "analysisProvider": "mock" }
```

서버는 현재 ready·문구를 고정 반환한다. 실제 AI 서버의 준비 상태를 검사하지 않는다. 화면은 ready/unavailable과 label을 검증하고 상태에 맞는 색상을 사용한다.

응답 전에는 상태 확인 중, 오류면 상태 확인 실패로 표시한다. 홈 진입 시 조회하고 화면 해제 후 도착한 응답은 무시한다. 대화 초기화로 다시 조회하지 않으며 배지 결과로 전송을 차단하지 않는다.

위치는 src/services/chat.ts, src/types/chat.ts, ChatServiceStatusBadge.tsx와 api-server/src/app.js다. 실제 연결에서는 상태 의미·인증·재조회·전송 차단 여부를 정식 계약으로 정한다. [전환 가이드](실제_서버_전환_가이드.md)를 참고한다.

build/lint와 프론트 서비스·API 상태 조회 검사가 통과했다. 브라우저 검증은 미실시다.
