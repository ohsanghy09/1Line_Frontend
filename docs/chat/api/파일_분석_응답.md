# 파일 분석 진행·결과 응답

최종 정리: 2026-11-04

## 서비스와 API

getChatReply(message, files, options)는 Promise<ChatReply>를 반환한다. options는 conversationId, signal, onProgress, onJobStarted를 받는다. 외부 JSON은 서비스에서 검증한다.

POST /api/chat에 message, 반복 files, conversationId를 FormData로 보내며 홈 파일 요청은 Prefer: respond-async를 사용한다. 서버가 작업 ID를 반환하면 GET /api/chat/jobs/:jobId를 조회한다. 완료 result.reply에 analysisId·conversationId를 붙여 화면에 전달한다.

ChatProgress는 title과 steps 배열이며 단계별 label/status를 가진다. 상태는 working/completed다. 진행과 취소·재개·시간 제한의 정확한 계약은 [진행 API](파일_분석_진행.md)를 기준으로 한다.

## 결과 필드

| 값 | 화면 역할 |
| --- | --- |
| kind | 단일·다중·변화 없음 등 카드 종류 |
| content | 카드 본문/제목 |
| analysis.activity, materialType, stage | 분류 정보 |
| analysis.files | 실제 파일명과 응답의 이전 버전 관계 |
| analysis.summary | 요약 또는 변화 없음 사유 |
| analysis.changes | 전후 비교·변화 유형·근거. 없으면 빈 배열 |
| analysis.groups | 다중 파일 분류 개수 |
| analysis.noChangeMessage | 선택적인 변화 없음 안내 |
| analysis.suggestedSaveMode | 저장 제안. 저장 완료 상태와 구분 |

실제 원본 파일은 보관하지만 분석은 서버 목 값이다. 홈 기본은 변화 없음이며 src/mocks/Home의 설정은 홈 분석에 적용되지 않는다. 실제 AI 연결 후에는 서버가 판단한 값을 화면용 타입으로 변환한다.

저장·수정·복원은 [카드 기록·수정](../구현_기능/카드_기록_수정.md)과 [세션 보관](../구현_기능/채팅_세션_보관.md)을 참고한다.
