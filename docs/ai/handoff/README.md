# AI 담당자 안내

기준일: 2026-11-06. [전체 안내](../../common/handoff/README.md) · [공통 시작](../../common/handoff/에이전트_시작_안내.md)

AI 서버는 홈 접수·진행·원본·초안 보관과 실제 모델 분석을 맡는다. 신규 활동은 제안만 하고 사용자가 확정하면 백엔드가 생성한다. 활동 전체 종합·성장·삭제 후 남은 원본 분석은 결과만 반환하며 DB 확정 쓰기는 백엔드 책임이다.

읽는 순서: [구현 환경](../../common/handoff/개발환경과_구현_범위.md) → [API](API_정의서.md) → [분석 입출력·검증](분석_입출력과_검증_규칙.md) → [프롬프트 전문](프롬프트_정의서.md) → [서버 간 전달](../../common/handoff/서버간_데이터_전달_계약.md) → [배포](../../common/integration/handoff/배포와_서버_연결.md) → [검증](../../common/integration/handoff/연동_검증_시나리오.md).

개발 소스·Python 가상환경·실행 스크립트는 제공하지 않는다. Python/FastAPI/Pydantic이나 공유 SQLite 설치는 요구하지 않는다. 문맥·원본을 서버 간 전달 규격으로 받고 홈 완료 초안을 백엔드가 확정 저장·직접 수정에 사용할 수 있게 게시한다. 응답만 브라우저에 보내고 초안 전달을 생략하면 저장이 실패한다. 프롬프트 전문은 이 문서 묶음에 포함했다.

프롬프트만으로 데이터 무결성을 보장하지 않는다. 선택한 언어의 검증기로 출력 구조·실제 활동 ID·파일 목록·원문 근거·스냅샷을 검증하고 백엔드도 재검증한다. 실패 시 모델 자동 재호출은 없다. Journey 출력 버전은 journey-v5, 활동 정보는 activity-metadata-v1이다. 키·모델은 서버 설정이며 프론트에 노출하지 않는다.
