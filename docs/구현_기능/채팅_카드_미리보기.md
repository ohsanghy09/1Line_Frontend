# 채팅 카드 미리보기

최종 정리: 2026-11-03

## 사용 방법

개발 서버 실행 후 `/example`에 접속한다. 사이드바가 없는 독립 페이지이며 ‘홈으로 돌아가기’로 홈 채팅에 복귀할 수 있다.

## 표시하는 컴포넌트

- 텍스트 경험 분석 카드
- 단일 파일 분석 · 변화 있음 카드
- 단일 파일 분석 · 변화 없음 카드
- 다중 파일 분석 카드
- 파일 분석 진행 카드
- 준비됨·사용 불가·조회 중·조회 실패 상태 배지

실제 홈의 `ChatReplyCard`, `FileAnalysisProgress`, `ChatServiceStatusBadge`와 기존 목 응답을 재사용한다. 카드 디자인을 복제하지 않으므로 공통 컴포넌트를 수정하면 홈과 미리보기에 함께 반영된다. 홈의 현재 목 모드를 바꾸지 않고 변화 있음·없음을 동시에 확인할 수 있다.

## 데이터와 버튼 확인

각 결과 카드 아래에 사용한 본문 컴포넌트 이름과 버튼별 현재 동작을 표시한다. ‘이 카드의 응답 데이터 보기’를 펼치면 해당 카드에 전달한 `ChatReply` JSON을 확인할 수 있다. 진행 카드도 진행 데이터를 펼쳐볼 수 있다.

저장·수정·활동 선택 버튼은 실제 구현과 같은 비활성 상태다. 클릭 실험을 위한 가짜 저장·수정 동작은 추가하지 않았다. 다중 파일의 ‘자료 확인’ 링크는 기존처럼 `/archive`로 이동하며 자료를 저장하지 않는다.

분석 요청을 새로 보내는 페이지는 아니며 미리보기 시각은 페이지를 연 시점으로 고정한다. 홈에서 제거한 시연 버튼은 다시 추가하지 않았다.
