# 채팅 기능

최종 정리: 2026-11-04. 전체 현황은 [현재 구현 상태](../현재_구현_상태.md)를 참고한다.

## 현재 동작

- 초기 AI 안내, 준비 배지 조회, 텍스트·파일·링크 전송을 제공한다.
- 글과 파일이 모두 없으면 일반 전송을 막고 한글 조합 중 Enter 제출을 방지한다.
- 파일 선택·드롭은 전송 전 첨부만 한다. 추가 선택·개별 삭제·파일만 보내기를 지원한다.
- 파일·링크는 서버 작업 ID로 진행을 조회하고 결과 카드로 전환한다. 텍스트 전용은 일반 대기를 사용한다.
- 홈 결과 카드의 저장·수정은 실제 로컬 REST API를 호출한다.
- 메시지·시각·첨부 표시·카드 수정/저장 상태와 접수된 작업을 sessionStorage에서 복원한다.
- 초기화·화면 해제 시 브라우저 조회를 취소하고 늦은 응답을 무시한다. 서버 기록 삭제는 아니다.
- 상태 변경 시 하단으로 스크롤하고 오류를 표시한다. 접수된 작업의 재확인과 초기화도 제공한다.

## 메시지 표시

사용자 말풍선 최대 너비는 80%, 하단 시각과 간격은 4px다. AI 카드는 기본 최대 85%, sm 이상 80%다. 실제 전송·응답 도착 시각을 방금 전/N분 전/현지 시각/날짜로 표시하고 30초마다 갱신한다. AI 하단에 Growth AI를 붙이며 정확한 시각은 마우스로 확인한다.

## 데이터·서비스·화면

Home은 chat 서비스로 입력을 보내고 ConnectedChatReplyCard로 결과를 표시한다. 서버가 입력을 보관하고 목 분석을 생성한다. 합성 응답은 테스트 전용으로 분리했다. 홈 목 설정은 api-server/src/mock-reply.js에서 관리한다.

| 위치 | 역할 |
| --- | --- |
| src/pages/Home.tsx | 입력·전송·대기·진행·초기화·복원 |
| src/services/chat.ts | 전송·링크·상태·작업 재조회·응답 검증 |
| src/services/records.ts | 활동 조회·저장·수정 |
| src/types/chat.ts | 화면용 메시지·결과·진행 구조 |
| src/utils/chatSession.ts | 세션 검증·보관·중복 방지 |
| src/components/chat/ConnectedChatReplyCard.tsx | 카드 수정본·저장 상태·모달 |
| api-server/src/mock-reply.js | 실제 입력을 보존하는 목 분석 |
| api-server/src/progress.js | 서버 시간 기반 목 진행 |
