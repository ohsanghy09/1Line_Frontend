# 자료 상세 패널 구현 현황

정리일: 2026-11-05. 진입: `/archive/:activityId?file=:fileId`. 공통 전제는 [문서 안내](../문서_안내.md)를 따른다.

## 구현된 동작

- 활동 상세의 자료 버튼이나 자료 ID 쿼리로 우측 Drawer를 연다.
- 자료명·유형·입력/업로드 시각·저장된 기록 요약·입력 내용을 표시한다.
- 선택 자료가 근거로 연결된 변화 이벤트만 표시한다. 변화 없는 자료에는 Before/After를 만들지 않는다.
- Timeline의 관련 이벤트 위치로 이동하는 링크를 제공한다.
- 모바일 전체 폭, sm 이상 440px 패널이다. native dialog로 배경 비활성화·초점 제한을 처리하며 X·Escape·배경 클릭으로 닫는다. 기존 초점이 남아 있으면 복귀한다.
- 로딩·실패·자료 없음을 구분한다. 실패 시 다시 열도록 안내하며 별도 재시도 버튼은 없다.

## API와 데이터

GET `/api/archive/activities/:id/materials/:fileId`

- 응답은 `activityId`, `file`, `events`, `versionHistory`다.
- 해당 활동의 확정 기록에 속하는 자료만 반환한다. 자료의 활동 이동 후 예전 주소는 404다. 이는 활동 소속 검사이며 사용자 인증·권한 검사는 아니다.
- 현재 요약은 파일별 본문 요약이 아닌 기록 단위 요약이다. 다중 파일은 같은 요약을 공유할 수 있어 ‘AI 기록 요약’으로 표시한다.
- 입력 내용은 사용자가 전송한 글이다. 파일 본문을 추출해 표시하는 기능은 없다.
- 근거는 현재 이름 문자열에서 같은 기록 안의 유일한 파일명 또는 명확한 텍스트/링크를 연결한다. 모호한 이름을 임의 자료 ID로 연결하지 않는다.
- 확정된 버전 관계가 없어 현재 서버의 `versionHistory`는 빈 배열이다. 목 버전 안내를 실제 관계로 바꾸지 않는다.

## 실제 연동 시 남은 작업

- 실제 근거 자료 ID·기록 ID·활동 ID 및 버전 관계 계약
- 자료별 요약과 기록 전체 요약의 범위 구분
- 원본 파일 다운로드·미리보기 UI 연결. GET `/api/files/:id`는 서버에 있지만 이 패널에는 연결하지 않았다.
- 파일 접근 권한·링크 만료·삭제·이동 후 관계 정책
