# 활동 상세 구현 현황

정리일: 2026-11-05. 경로: `/archive/:activityId`. 공통 전제는 [문서 안내](../문서_안내.md)를 따른다.

## 구현된 동작

- 활동 ID로 기본 정보·활동 전체 요약·자료 폴더·Timeline 데이터를 조회한다.
- 활동 유형·상태·역할·기간·요약을 표시한다. 값이 없으면 서버의 미설정 안내를 표시한다.
- 자료 폴더를 처음 모두 펼치고 폴더 ID별로 독립적으로 접고 펼친다.
- 자료 행에 자료명·유형·입력/업로드 시각을 표시하고 선택 시 [자료 상세 패널](자료_상세_패널.md)을 연다.
- 나의 발자국 목록과 해당 활동의 [Project Timeline](프로젝트_타임라인.md)으로 이동한다.
- 활동 ID가 바뀌면 조회·펼침 상태를 새로 시작하고 이전 응답을 무시한다.

## API와 데이터

GET `/api/archive/activities/:id`

- 현재 `getFootprintActivity()`가 활동 정보와 `folders`, `timeline`을 함께 받는다.
- 폴더는 DB의 독립 엔터티가 아니라 확정 자료의 유형별 그룹이다. 폴더 개수는 실제 자료 수다.
- 업로드 원본은 실제 파일 ID, 파일 없는 텍스트·링크는 기록 ID를 사용한다. 원본이 없는 독립 카드 자료는 별도 합성 ID를 사용하며 실제 파일 ID로 취급하지 않는다.
- 활동 정보는 DB 저장값이다. ‘AI 활동 요약’이라는 화면 제목이 실제 AI 연동을 뜻하지 않는다. 저장된 요약의 생성 경로와 미설정 상태를 구분해야 한다.

## 오류와 남은 작업

- 로딩·실패·활동 없음·폴더 없음·빈 폴더를 처리한다. 404는 없음으로, 다른 오류는 실패로 구분한다.
- 실패 시 안내를 표시한다. 이 화면에는 목록·Journey와 같은 재시도 버튼이 없다.
- 실제 서버의 활동 상세·분류 그룹·자료 ID·전체 요약 계약이 필요하다.
- 독립 폴더 CRUD·활동 관리 화면·실시간 구독은 없다. 조회 오류를 원본 예시로 대체하지 않는다.
