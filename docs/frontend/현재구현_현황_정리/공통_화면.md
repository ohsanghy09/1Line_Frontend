# 공통 화면 구현 현황

정리일: 2026-11-05. 공통 전제와 검증 범위는 [문서 안내](문서_안내.md)를 따른다.

## 구현된 동작

- MainPage에서 Sidebar와 자식 페이지 Outlet을 표시한다.
- 홈·Growth Journey·나의 발자국 메뉴가 URL에 따라 활성화된다. 활동 상세·Timeline에서도 나의 발자국 메뉴가 활성화된다.
- 브랜드를 누르면 홈으로 이동한다.
- Sidebar 하단에 서버 활동 개수를 표시한다. 최초 조회 및 같은 창의 `1line:activities-changed` 이벤트에서 갱신한다.
- 활동 개수 최초 조회 실패 시 고정 숫자 대신 ‘나의 활동 기록’을 표시한다. 이후 갱신 실패 시 기존 값이 남을 수 있다.

## 데이터·API

| API | 용도 | 현재 데이터 |
| --- | --- | --- |
| GET `/api/activities` | 활동 선택지·Sidebar 활동 개수 | 개발 서버 SQLite의 활동 |

프로필의 ‘김성장’과 아바타는 고정 예시다. 실제 로그인 사용자 조회가 아니다. 설정 아이콘은 별도 화면·클릭 동작이 없다.

## 실제 연동 시 남은 작업

- 인증·사용자 정보·사용자별 활동 범위와 권한 계약
- 활동 변경 후 개수 갱신 방식 및 다른 탭·열린 화면의 갱신 정책
- 설정 화면이 필요한 경우 별도 기능 범위 정의
