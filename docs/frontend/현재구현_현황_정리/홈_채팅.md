# 홈 채팅 구현 현황

정리일: 2026-11-05. 경로: `/`. 공통 전제는 [문서 안내](문서_안내.md)를 따른다.

## 구현된 사용자 흐름

1. 텍스트·파일 또는 링크를 입력하고 전송한다. 파일 선택·드롭만으로 자동 전송하지 않으며 전송 전 개별 삭제를 지원한다.
2. 서버에 입력을 접수하고 분석 결과를 카드로 표시한다. 텍스트는 동기 응답, 파일·링크는 작업 ID를 받아 진행 상태를 조회한다.
3. 텍스트 분석·단일 파일 변화 있음/없음·다중 파일·링크 응답을 해당 카드로 표시한다.
4. 활동·자료 유형을 확인·수정하고 기록을 확정 저장한다. 저장 전 카드 수정과 저장 후 서버 PATCH를 구분한다.
5. 저장·수정 성공 시 최근 목록과 Sidebar 활동 개수를 갱신한다.

- 변화 없는 단일 파일은 연결된 기존 활동으로 바로 아카이브 저장한다. 수정 범위는 활동·자료 유형이다.
- 다른 카드의 활동 확인 흐름에서 신규 활동 생성 또는 기존 활동 정보의 명시적 적용을 지원한다.
- 다중 파일은 파일 목록을 포함한 하나의 분석 기록으로 저장한다. ‘자료 확인’은 `/archive`로 이동한다.
- changes가 비어 있으면 Timeline 이벤트를 생성하지 않는다. 목 변화 이벤트의 Turning Point 값은 false다.
- 최근 활동은 변경 시각순, 최근 기록은 최초 저장순으로 각각 최대 3개다. 활동 상세·자료 패널로 이동한다.
- 같은 탭의 sessionStorage로 메시지·시각·수정값·저장 ID와 접수된 작업을 복원한다. 새 대화는 화면·세션을 초기화하며 서버 기록을 삭제하지 않는다.

## 현재 API 연결

| 메서드·경로 | 화면에서 사용하는 용도 |
| --- | --- |
| GET `/api/health` | 준비 상태 배지. ready는 개발 서버 고정 응답 |
| POST `/api/chat` | 텍스트·파일 multipart 전송, 분석 초안 생성 |
| POST `/api/chat/links` | URL 접수·작업 생성 |
| GET `/api/chat/jobs/:id` | 진행·완료 결과 조회, 접수된 작업 재개 |
| GET `/api/activities` | 기존 활동 선택·확인 |
| POST `/api/records` | 분석 초안의 확정 저장 |
| PATCH `/api/records/:id` | 저장된 기록의 활동·자료 유형 등 수정 |
| GET `/api/home/recent` | 최근 활동·추가 기록 조회 |

파일·링크 작업은 400ms 간격으로 순차 조회하며 전체 폴링 제한은 30초다. 현재 파일 제한은 최대 10개·각 10MiB, 텍스트는 20,000자다. 최종 서버 제한·진행 방식은 협의 대상이다.

서버에는 대화 메시지 조회·원본 파일 다운로드 API도 있으나 현재 대화 복원은 sessionStorage를 사용하며, 원본 다운로드는 자료 패널 UI에 연결하지 않았다.

## 실제 값과 목 값

| 구분 | 내용 |
| --- | --- |
| 실제 입력·저장 | 입력 글·URL·파일 원본과 이름·시각·작업/분석/기록/활동 ID, 저장·수정 결과 |
| 목 분석 | 활동 매칭·자료 유형·요약·단계·버전 안내·변화·비교·근거 문구 |
| 목 진행 | 서버 시간 기준 700ms씩 계산하는 4단계. 실제 AI 작업 진행률 아님 |

일반 홈 요청은 서버 기본 `no-change` 모드를 사용한다. 실제 문서 본문 추출·웹페이지 수집·기존 자료 비교·AI 호출은 하지 않는다. 새 활동 메타정보 추출도 목 분석에서는 null이며 확인·저장된 값과 구분한다.

## 오류·복원과 한계

- 입력 제한·잘못된 URL·서버 실패·시간 초과·진행 실패를 표시한다. 초기화·이탈 시 브라우저 요청을 취소하고 이전 응답 반영을 차단한다.
- 작업 ID가 있는 요청은 파일을 다시 올리지 않고 진행 조회를 재개한다.
- 작업 접수 전 중단된 업로드·동기 텍스트 요청은 자동 복원하지 않는다. 미전송 글·File 객체·열린 모달도 복원 대상이 아니다.
- 브라우저 취소가 서버 AI 작업 취소를 뜻하지 않는다. 실제 작업 취소·재시도·중복 방지는 최종 계약에서 정해야 한다.

## 실제 연동 시 남은 작업

- 인증·파일 전송 및 보관·분석 요청/결과·진행 상태 계약 적용
- 실제 AI 분류·활동 매칭·요약·변화 없음·Turning Point 판단과 검증
- 활동 안내 문구와 실제 저장 대상 ID 일치, 근거 자료 ID와 버전 관계 확립
- 분석 초안과 확정 기록의 수명·중복 저장·수정·삭제 정책
- 실제 AI 작업 시간에 맞춘 폴링·타임아웃·오류 및 복원 정책
