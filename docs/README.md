# 프로젝트 문서

개발 문서와 참고 자료를 `docs/` 아래에 모아 관리한다.

## 작업을 이어갈 때

Growth Journey는 journey-v3부터 [성장 분야도 AI 분석 분류](journey/성장_분석_API.md)를 사용한다. 고정 목록 대신 실제 이벤트의 분야를 생성하며 이전 저장 결과는 유지한다. 서버 재시작 후 분석 갱신에서 반영한다.

최신 자료 기준: [채팅 자료 제외](footprints/채팅_자료_제외.md). 입력 채팅은 참고 자료·최근 추가 자료로 표시하지 않는다. 파일·링크 확정 기록에는 함께 입력한 채팅을 복사하지 않고 자료 상세의 ‘입력한 내용’도 제거했다. 기존 자료의 입력문은 상세·검색에서 제외하며 DB 행과 별도 채팅 이력은 보존한다.

최신 채팅 기능: [대화로 활동 정보 수정](chat/구현_기능/대화로_활동_정보_수정.md). 역할·상태·기간·전체 요약을 말로 요청하면 해당 DB 값만 직접 변경한다. 별도 정정 기록·모달은 없으며 이후 자료 저장 시 AI가 다시 갱신할 수 있다.

최신 추가 기능: [활동 전체 정보 AI 자동 갱신](footprints/활동_정보_AI_갱신.md). 자료 저장 후 활동 요약·상태·기간·역할을 AI가 종합하며 실패 시 자료와 기존 정보는 보존한다. 백엔드와 AI 서버 재시작이 필요하다. 사용자 요청으로 Swagger 최신화는 진행하지 않는다.

최신 홈 UI: 신규 활동 추가는 확인 모달 없이 카드의 ‘새 활동으로 저장’ 또는 ‘기존 활동에 연결’로 판단한다. 신규 추가 과정에서 활동 전체 요약·기간·역할을 입력받지 않는다. [현재 기능 기록](chat/구현_기능/홈_응답_구분_및_활동_확인_저장.md)을 따른다.

개선 범위는 [사용자 확인 기반 기록 및 활동 관리 개선계획](integration/사용자_확인_기반_기록_및_활동_관리_개선계획.md)에 정리했다. 1단계인 [홈 응답 구분·활동 확인 저장](chat/구현_기능/홈_응답_구분_및_활동_확인_저장.md)을 구현하고 자동 검사를 완료했다. 실제 모델·브라우저 확인과 나머지 개선은 대기다.

사용자 프로필 설정의 [전체 데이터 삭제](chat/구현_기능/전체_데이터_삭제.md)를 추가했다. 확인 문구 입력 후 실행하며 홈·성장 분석 중에는 삭제를 막는다. 기능 구현만으로 실제 DB를 삭제하지는 않았다.

**[현재 작업 인수인계](integration/현재_작업_인수인계.md)부터 읽는다.** 홈·Growth Journey 실제 AI 연동, 동적 분류/아이콘, DB 초기화·예시 자동 생성 제거, 실행 명령, 검사 결과와 다음 작업을 정리했다. 이전 단계별 계획보다 이 문서의 현재 상태를 우선한다.

현재 홈의 텍스트·단일/다중 파일·링크는 FastAPI와 실제 OpenAI 분석으로 연결했다. AI 서버는 기존 활동을 확인하거나 신규 활동을 제안하고 원본·분석 초안을 보관한다. 신규 활동 생성은 카드의 저장 선택 시 백엔드가 수행한다. 일반 대화는 분석 없는 말풍선으로 표시한다. 기존 활동 분류 수정은 유지하고 신규 제안은 카드에서 새 활동 저장 또는 기존 활동 연결로 확정한다.

다음은 바탕화면 `1Line_AI_시나리오_자료/00_사용안내.md` 순서로 실제 화면을 확인하고 발견한 문제를 보완하는 단계다. Growth Journey도 확정 기록 조회·실제 AI 분석·백엔드 결과 저장·조회로 연결했다. [성장 분석 API](journey/성장_분석_API.md)를 따른다. 실제 모델 통합 검사는 통과했지만 사용자 브라우저 전체 시나리오 완료는 아직 확인하지 않았다. 최종 협업용 API 명세·ERD와 외부 배포는 후속 작업이다.

최신 상태(2026-11-06): 사용자 요청으로 실제 공유 DB를 비웠고 예시 활동 자동 생성도 제거했다. 문서 갱신 시 8개 테이블이 모두 0건이다. 새로운 사용자 입력부터 확인한다. Journey는 화면 진입 시 저장 결과만 조회하며 실제 AI는 ‘성장 분석하기 / 분석 갱신’에서 호출한다. 자동 분석은 논의한 제안이며 아직 적용하지 않았다. 성장 유형과 이모지는 AI가 생성하고 분야 기준은 유지한다.

관련 문서는 다음 순서로 읽는다.

1. [공통 개발 규칙](개발_규칙.md): 작업 방식과 보존 기준.
2. [홈 실제 AI 연동](../ai-api-server/docs/홈_실제_AI_연동.md), [AI 실행 안내](../ai-api-server/README.md): 실제 요청·응답·실행·오류 처리.
3. [카드 기록·수정](chat/구현_기능/카드_기록_수정.md), [홈 현재 상태](chat/현재_구현_상태.md): 카드 동작과 프론트 구현.
4. [나의 발자국 안내](footprints/README.md), [Growth Journey 안내](journey/README.md): 조회·검색·DB와 화면별 후속 작업.
5. [개발 서버 연동 계획](integration/개발서버_분리_연동_작업계획.md), [API 계약 안내](integration/API_계약/문서_안내.md), [Swagger 사용 안내](integration/API_계약/Swagger_사용안내.md): 명세·검증·담당 파트 전달 준비.

[이전 인수인계](integration/다음_작업_인수인계.md)와 [개발 기록](chat/개발_기록.md)은 결정 이력이다. 당시의 미구현 안내를 현재 상태로 해석하지 않는다. 채팅 세부 문서는 [docs/chat](chat/README.md)에 모았다.
