# 프로젝트 문서

개발 문서와 참고 자료를 `docs/` 아래에 모아 관리한다.

## 작업을 이어갈 때

**[현재 작업 인수인계](integration/현재_작업_인수인계.md)부터 읽는다.** 현재 구현, 실행 명령, 연결 오류와 재전송 수정, 바탕화면 시나리오 자료, 검사 결과와 남은 작업을 정리했다. 이전 문서의 단계별 계획보다 이 문서의 현재 상태를 우선한다.

현재 홈의 텍스트·단일/다중 파일·링크는 FastAPI와 실제 OpenAI 분석으로 연결했다. AI 서버가 공유 SQLite에서 기존 활동을 확인하거나 신규 활동을 생성하고 원본·분석 초안을 보관한다. 사용자의 기록 버튼으로 백엔드가 확정 저장한다. 카드 수정은 기존 활동·자료 유형으로 통일했다.

다음은 바탕화면 `1Line_AI_시나리오_자료/00_사용안내.md` 순서로 실제 화면을 확인하고 발견한 문제를 보완하는 단계다. 실제 모델 통합 검사는 통과했지만 사용자 화면의 전체 시나리오 완료는 아직 확인하지 않았다. Growth Journey는 목 응답이며 최종 협업용 API 명세·ERD와 외부 배포는 후속 작업이다.

관련 문서는 다음 순서로 읽는다.

1. [공통 개발 규칙](개발_규칙.md): 작업 방식과 보존 기준.
2. [홈 실제 AI 연동](../ai-api-server/docs/홈_실제_AI_연동.md), [AI 실행 안내](../ai-api-server/README.md): 실제 요청·응답·실행·오류 처리.
3. [카드 기록·수정](chat/구현_기능/카드_기록_수정.md), [홈 현재 상태](chat/현재_구현_상태.md): 카드 동작과 프론트 구현.
4. [나의 발자국 안내](footprints/README.md), [Growth Journey 안내](journey/README.md): 조회·검색·DB와 화면별 후속 작업.
5. [개발 서버 연동 계획](integration/개발서버_분리_연동_작업계획.md), [API 계약 안내](integration/API_계약/문서_안내.md), [Swagger 사용 안내](integration/API_계약/Swagger_사용안내.md): 명세·검증·담당 파트 전달 준비.

[이전 인수인계](integration/다음_작업_인수인계.md)와 [개발 기록](chat/개발_기록.md)은 결정 이력이다. 당시의 미구현 안내를 현재 상태로 해석하지 않는다. 채팅 세부 문서는 [docs/chat](chat/README.md)에 모았다.
